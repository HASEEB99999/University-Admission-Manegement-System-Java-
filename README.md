# University Admission Manegement System-Java-
# 🎓 Admission Management System

A console-based **Admission Management System** built in **Java** that simplifies the student admission process. This system handles student registration, admission form submission, fee management, and record keeping.

---

## ✨ Features

- **Student Registration** – Add new students with personal details
- **Admission Form Management** – Submit and track admission applications
- **Student Search** – Search students by ID and name
- **View All Students** – Display all registered students
- **Delete/Update Records** – Modify or remove student records
- **Admin Login** – Secure access to administrative functions
- **Merit List** - It show merit of students overall

## 🚀 How to Build & Run

### Prerequisites
- Java Development Kit (JDK) 11 or higher
- IntelliJ IDEA (or any Java IDE)
- Git (to clone the repository)

### Method 1: Using IntelliJ IDEA 
1. Open IntelliJ IDEA
2. Click **File** → **Open** → Select the project folder
3. Wait for IntelliJ to index the files
4. Navigate to `src/main/java/Main.java`
5. Click the green **Run** button ▶️

### Method 2: Using Blue J
1. Install Blue J
2. Open the folder on it
3. Compile all files
4. Right Click on Main file and press enter
